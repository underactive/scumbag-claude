# Version History

| Ver | Changes |
|-----|---------|
| v0.1.0 | Initial release: menubar monitor for Claude Code tmp files with per-project breakdown, status notifications, configurable thresholds, and one-click cleanup |
| v0.2.0 | Audit remediation: path validation on symlink deletion, settings clamping, typed delete confirmation, batch delete, accessibility labels & keyboard shortcuts, notification permission detection, timer tolerance, pluralization fixes, deprecated API cleanup. Dynamic menubar icon color: icon turns orange at warning threshold and red at critical threshold, with system-tinted template icon for normal status. Settings dialog + right-click About menu: replace MenuBarExtra with custom NSStatusItem, move settings into a separate window, add right-click context menu with About dialog (app icon, version, GitHub link), SF Symbol fallback icon when resource image is missing, reset stale confirmation state on popover reopen, remove dead code |
| v0.2.1 | **UI polish & new setting.** Footer buttons: replaced plain-text links with bordered macOS-native buttons (`.buttonStyle(.bordered)` + `.controlSize(.small)`), hoisted shared modifiers to parent HStack. Hover effects: added `HoverButtonStyle` with configurable hover color for icon-only buttons (refresh, chevron, trash, xmark); delete buttons use red hover tint. Inline confirm/cancel buttons (project and file level) upgraded to bordered style with `.tint(.red)` on Delete. Menubar icon: replaced generic drive icon with scumbag cap silhouette mask generated from `assets/ScumbagCap.png`. File delete icon changed from `xmark.circle` to `xmark`. Popover now opens focused (key window) on first click. New setting: "Show size in menu bar" toggle (`showSizeInMenuBar`, default true) to show/hide total disk usage text next to menubar icon, with reactive Combine subscriber for immediate updates. |
| v0.3.0 | **Auto-update.** New `UpdateService` checks GitHub releases API daily (configurable). In-popover update banner with download progress, one-click install & restart. "Check for Updates..." in right-click menu. Update status in About dialog. "Check for updates automatically" toggle in Settings. Shell-script self-replacement with quarantine clearing. HTTPS-only download validation. |
| v0.3.1 | **Bug fix.** Threshold clamp ranges were silently capping warning at ~10 GB and critical at ~50 GB, causing incorrect status levels for users with higher thresholds. Raised upper bounds to ~1 TB. |
| v0.3.2 | **Bug fix.** Auto-update relaunch failed silently after replacing the app bundle. Added Launch Services re-registration (`lsregister -f`), `open -n` for reliable relaunch, `set -e` for error checking, and a brief sleep for filesystem settle time. |
| v0.3.3 | **Bug fix.** App bundle from GitHub Releases crashed on launch due to SPM resource bundle being placed in `Contents/Resources/` instead of `Contents/MacOS/` where `resource_bundle_accessor.swift` looks. Fixed Makefile to copy resource bundle next to the executable. |
| v0.3.4 | **Maintenance.** Disabled auto-update and release workflow until Developer ID code signing and notarization are configured. Unsigned release builds are blocked by Gatekeeper. Improved updater script with Launch Services re-registration and reliable relaunch. |
| v0.3.5 | **FSEvents monitoring, growth rate tracking & symlink visibility.** Replaced timer-only polling with FSEvents as primary filesystem change detection, watching `/private/tmp` and `~/.claude/projects/`. Detection latency reduced from 5–30s to ~2.5s worst case. Existing timer kept as fallback safety net. Track file sizes across successive scans to compute per-file growth rates; displays "↑ X.X MB/min" indicators on project and file rows for actively growing files, surfacing runaway agent output in real-time. Symlink scope indicators: out-of-scope symlink targets show "link only" purple badge so users know deletion only removes the symlink. Deduplication visibility: blue "×N" badge when multiple symlinks share a resolved target, with tooltip explaining size is counted once. Broken symlink cleanup: project subtitle shows broken count, footer "Clean Broken (N)" button with confirm/cancel flow removes all dangling symlink entries globally. |
| v0.4.0 | **Statistics & historical graphs.** New `HistoryService` records scan snapshots to `~/Library/Application Support/com.esison.claude-tmp-monitor/history.json` with two-tier aggregation (raw resolution ≤1h, 5-minute buckets beyond). New Statistics window with SwiftUI Charts: area+line chart of total size over time, segmented picker for 1h/24h/7d ranges, current/peak/average summary stats, and empty state. Accessible from footer "Stats" button, right-click menu, or Settings. Configurable retention (1–30 days, default 7). Data saved every 60s + on app termination. **File Write Watchdog.** New `WatchdogService` manages a Claude Code PreToolUse hook that blocks Write/Edit/Bash operations targeting files outside user-whitelisted directories. Settings UI with toggle, directory allowlist management (add via `NSOpenPanel`, remove inline), and hook installation status indicator. Hook script uses `osascript -l JavaScript` (JXA) for JSON parsing with zero external dependencies. Bash commands are checked for destructive patterns (`rm`, `mv`, `>`, `git clean`); `/tmp` and `/private/tmp` are always allowed. Blocked operations trigger macOS notifications and are logged to `~/Library/Application Support/com.esison.claude-tmp-monitor/watchdog.log`. Fail-open design: if JSON parsing fails, operations proceed. |
| v0.4.1 | **Blocked commands (watchdog extension).** Added configurable blocked commands list to the file write watchdog. Inherently dangerous commands (`passwd`, `sudo`, `su`, `shutdown`, `reboot`, `halt`, `poweroff`, `mkfs`, `newfs`, `diskutil`, `csrutil`, `nvram`, `dscl`) are rejected by the hook regardless of target directory. Position-aware regex avoids false positives on path arguments (e.g., `cat /etc/passwd` is allowed). Commands are user-configurable via Settings UI with inline text field and add/remove controls. |
| v0.4.2 | **Tabbed settings with split watchdog toggles.** Refactored Settings window from a flat VStack to a 3-tab TabView (General, File Operations, Blocked Commands). Split the monolithic `watchdogEnabled` boolean into two independent toggles: `fileOpsEnabled` controls directory-based Write/Edit/Bash checks, `commandWatchdogEnabled` controls blocked commands enforcement. Hook script is conditionally generated based on enabled features; matcher adapts (`Write\|Edit\|Bash` vs `Bash`). Migration from legacy `watchdogEnabled` key. Each watchdog tab shows explanatory help text and shared hook status indicator. Audit fixes: `shellEscape()` strips control characters, `regenerateHookScript()` recovers from externally-deleted script, `ForEach` uses stable element identity. |
| v0.4.3 | **Enhanced statistics with stacked bar charts.** Statistics window now shows stacked bar charts color-coded by project for 24h/7d/30d ranges, with hover tooltips showing per-project size and percentage breakdown. Tooltip appears to the right of hovered bar (flips left near chart edge), adapts to window resize. 1h range retains existing area+line chart. New 30-day time range added to `TimeRange` enum. Flow layout legend below chart maps colors to project names. Retention hint shown when 30d selected but history retention is below 30 days. Stats window enlarged to 700×550. 12-color palette with deterministic project-to-color mapping. |
| v0.4.4 | **Project search, sort, timestamps, and batch delete.** Added search/filter field and sort menu (Size/Name/Date) between the status bar and project list. Typing filters projects by display name (case-insensitive). Sort order applies to both projects and files within expanded projects. File rows show compact relative timestamps ("2m", "3h", "2d") next to size; project subtitles include modification time. Selection circles on file rows enable multi-file selection; "Delete (N)" footer button batch-deletes selected files with a single scan. |
| v0.5.1 | **Code signing, notarization, and auto-update re-enable.** Release workflow now triggers on `v*` tag push, signs with Developer ID certificate, notarizes via Apple, and staples the ticket. `make sign` target auto-detects Developer ID cert; `make install` signs before copying. Moved SPM resource bundle to `Contents/Resources/` to fix codesign bundle format error. Removed `--deep` codesign flag. Re-enabled auto-update (was disabled pending code signing). |
| v0.5.0 | **Disk pressure detection, active session detection, and menubar trend indicator.** Added system-level disk space monitoring via APFS-aware `volumeAvailableCapacityForImportantUsageKey` API — orange "Low Disk Space" banner in popover when free space drops below configurable threshold (default: 10 GB), with episode-based notification dedup and fail-open design. New settings: `diskPressureEnabled` (default: true), `diskPressureThresholdGB` (default: 10, range: 1–500 GB). Active session detection: projects with files modified within 60 seconds or actively growing show a pulsing green "live" badge. Menubar trend indicator: ↑/↓ arrows next to size showing whether total monitored size is growing or shrinking between scans (1 KB dead zone). |
| v0.5.2 | **DMG distribution.** Release workflow now packages the signed+notarized app as a compressed DMG (UDZO) instead of a zip archive. Auto-update service downloads `.dmg` assets, mounts with `hdiutil attach`, copies the `.app` out, and detaches on a background thread. |
| v0.5.3 | **Bug fix.** Fixed comically tall settings window caused by unconstrained `Spacer()` expanding infinitely inside `NSHostingController`. Added fixed frame to `TabView` content and made the settings window non-resizable. |
| v0.6.0 | **Sparkle auto-update.** Replaced custom 445-line `UpdateService` (GitHub API polling, DMG download/mount/extract, shell script self-replacement) with Sparkle 2.x framework. EdDSA signature verification on updates, native macOS update UI, appcast feed hosted on GitHub Pages. Removed in-popover update banner (~98 lines), simplified About dialog, rewired Settings toggle to Sparkle's `SPUUpdater`. Inside-out code signing for embedded framework. Release workflow updated with Sparkle tools, EdDSA DMG signing, and automatic appcast generation. Resolves former known issues: Gatekeeper quarantine, no delta updates, no checksum verification. Styled DMG installer with custom background image, app icon positioning, and Applications folder shortcut for drag-to-install (via `create-dmg`). |
| v0.6.2 | **Ko-fi support button.** Added native "Support me on Ko-fi" button to the About window, styled with Ko-fi brand color (`#72a4f2`) and coffee cup emoji. Opens Ko-fi page in default browser via SwiftUI `Link`. |
